1. QORT-Former

QORT-Former is the first Transformer-based real-time framework for estimating 3D poses of two hands and an object. It introduces query-division, contact integration, and a three-step decoder update to achieve 53.5 FPS and state-of-the-art accuracy on H2O and FPHA datasets.

Figure: FPS vs Error trade-off on H2O. QORT-Former achieves both real-time speed and top-tier accuracy.

2. HandVQA

HandVQA is a large-scale benchmark for diagnosing spatial reasoning failures in VLMs using fine-grained hand pose questions. It includes over 1.6M multiple-choice questions across five reasoning categories: angles, distances, and relative positions in 3D.

Figure: Accuracy comparison of VLMs on HandVQA before and after fine-tuning.

3. 4D Instruct-GS2GS

4D Instruct-GS2GS extends Instruct-GS2GS to dynamic scenes. It enables real-time semantic editing of 4D Gaussian Splats using natural language prompts, preserving temporal and spatial consistency through iterative dataset updates and contact-aware query refinements.

Figure: Visual results showing semantic scene edits over time using 4D Instruct-GS2GS.
